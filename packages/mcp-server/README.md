# MCP server — specification only

Future local adapter exposes selected snapshot data through a minimal, read-only policy boundary. Aggregate access and untrusted third-party text access must be distinct. No automatic external model access, network uploads, write tools or filesystem browsing. Treat creator labels as untrusted text too.

Optional local Ollama integration is later work, outside v1. Models may organise data, never tell users how to feel. Source captions must not become instructions or authorise actions. Provenance and capability restrictions reduce risk; sanitisation is not proof of prompt-injection immunity. No MCP or model code now.
